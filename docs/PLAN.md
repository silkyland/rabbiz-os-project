## 4. Audit findings

- **[blocker] Samsung Secure Boot e-fuse on BL1/BL2/S-Boot**: Stock BL1/BL2/S-Boot cannot be replaced with unsigned code. **Mitigation:** Unlock bootloader (`OEM Unlock` + Download Mode) and flash `uniLoader` in `boot.img` (`vbmeta` disabled), which gives a clean Linux boot environment without touching BL1/BL2.
- **[blocker] No Wi-Fi in `exynos850-a217f.dts`**: Mainline Linux on A21s has no Wi-Fi driver enabled yet. **Mitigation:** Enable USB-C Gadget RNDIS/ECM (`g_ether`) in initramfs/kernel + host NAT sharing, or use a USB-C Ethernet/Wi-Fi dongle over OTG.
- **[major] 3GB RAM ceiling (`2767544 kB`)**: Native Linux frees ~1GB+ previously used by Android, but Steam Client + Gamescope + FEX-Emu still need ZRAM (2–3GB) + swapfile on `userdata` eMMC (`&mmc_0`).
- **[major] Bricking risk without backup**: Flashing `boot`/`vbmeta`/`userdata` without stock recovery plan can soft-brick. **Mitigation:** `M0` requires downloading matching `SM-A217F` stock firmware (`AP`/`BL`/`CSC`) and verifying `heimdall` connectivity before flashing anything.

## 7. Design decisions

### Decision 1: `uniLoader` (`a21s_defconfig`) in `boot.img` as Linux Bootloader (closes Gap 1, Gap 2)
- **Decision:** Unlock A21s bootloader (`OEM Unlock` + Download Mode), disable `vbmeta` verification, and flash `samsungexynos850/uniLoader` (`a21s_defconfig`) + `samsungexynos850/linux` (`staging`) into `boot`.
- **Reversibility:** ONE-WAY (unlocking Samsung bootloader trips Knox e-fuse permanently; flashing `boot.img` itself is reversible via Heimdall stock `AP` flash).
- **Rationale:** `uniLoader` has an explicit `a21s_defconfig` and bypasses Samsung S-Boot's Android-specific ATAGs/ramdisk quirks.
- **Rejected:** Replacing BL1/BL2 (impossible due to Samsung Secure Boot e-fuse); `u-boot` (`e850-96_defconfig` is for the dev board, not `a21s`).

### Decision 2: USB-C RNDIS (`g_ether`) in Initramfs for First Boot & Networking (closes Gap 2, Gap 3)
- **Decision:** Build an initramfs with `usb_f_rndis` / `g_ether` (`172.16.42.1`) + `dropbear` SSH + `fbcon`/`simple-framebuffer` debug output so we can SSH into the A21s over the USB-C cable immediately on boot, even if display/Wi-Fi need debugging.
- **Reversibility:** REVERSIBLE
- **Rationale:** `&usbdrd` is `status = "okay"` in `exynos850-a217f.dts`, whereas Wi-Fi is not yet supported.

### Decision 3: Native ARM64 Linux Rootfs on `userdata` + ZRAM (closes Gap 3, Gap 4)
- **Decision:** Format/use `userdata` (or a partition/ext4 image) for an ARM64 Linux rootfs (Arch Linux ARM64 / postmarketOS edge + Mesa `panfrost`/`panvk` + `gamescope` + ZRAM) and pull Valve's SteamOS ARM64 / FEX-Emu / Proton ARM64 runtime.
- **Reversibility:** REVERSIBLE (can restore stock Android anytime via Heimdall).
