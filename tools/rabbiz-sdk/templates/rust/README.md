# RabbizOS Rust App Template (`--template rust`)

First-class native Rust application using the `rabbiz-sdk` crate (`rabbiz_sdk::app::AppState`, `rabbiz_sdk::ui::*`, `rabbiz_sdk::storage::*`, `rabbiz_sdk::testing::TestHarness`).

## Quick Start
```sh
rabbiz new my-rust-app --template rust
rabbiz test my-rust-app
rabbiz pack my-rust-app
```
