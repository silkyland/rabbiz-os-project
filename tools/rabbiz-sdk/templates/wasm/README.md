# RabbizOS WebAssembly App Template (`--template wasm`)

Portable, capability-sandboxed WebAssembly (`.wasm`) application targeting `wit/rabbiz-app.wit` (`rabbiz:app@0.1.0`) and executed by `rabbiz-wasm-runner`.

## Quick Start
```sh
rabbiz new my-wasm-app --template wasm
rabbiz pack my-wasm-app
```
