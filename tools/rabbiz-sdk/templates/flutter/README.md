# RabbizOS Flutter App Template (`--template flutter`)

Flutter/Dart application using `packages/rabbiz_sdk_dart` (`package:rabbiz_sdk/rabbiz_sdk.dart`) and hosted on RabbizOS via `rabbiz-flutter-runner` with `RABBIZ_FORCE_SOFTWARE=1` compatibility.

## Quick Start
```sh
rabbiz new my-flutter-app --template flutter
rabbiz pack my-flutter-app
```
